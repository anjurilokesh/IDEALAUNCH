# IDEALAUNCH — Startup Radar 🚀

A unique **Dark Futuristic UI** Startup Ideas Discovery Platform built with only HTML, CSS and JavaScript.

## Pages
Login, Dashboard, Explore Ideas, Saved Ideas, Idea Details and Profile.

## Features
- sessionStorage login and protected pages
- validation and logout
- search and category filtering
- favourites / saved ideas
- idea scoring
- Idea of the Day
- responsive design
- radar-style startup dashboard

## Mandatory JS concepts
Arrays, objects, functions, map(), filter(), find(), DOM manipulation, events, forms, validation and sessionStorage.

## Run
Open `index.html`, or use VS Code Live Server.

## GitHub
Create a repository, upload the entire project, commit and push.

## Netlify
Import the GitHub repository in Netlify. No build command is needed; publish directory is `/`.
