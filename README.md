# 🚀 IDEALAUNCH

### Discover Ideas. Build the Future.

IDEALAUNCH is a Startup Ideas Discovery Platform created using:

- HTML
- CSS
- JavaScript

## 🎨 UI Design

The project uses a Dark Futuristic UI design.

## ✨ Features

- Session-based login
- Login form validation
- Protected pages
- Logout
- Dashboard
- Startup idea listing
- Search
- Category filtering
- Favourite/Saved ideas
- Idea details
- User profile
- Responsive design

## 📄 Pages

1. Login
2. Dashboard
3. Explore Ideas
4. Saved Ideas
5. Idea Details
6. Profile

## 🧠 JavaScript Concepts

- Arrays

- Functions
- map()
- filter()
- find()
- DOM manipulation
- Events
- Forms
- Form validation
- sessionStorage
